Architectural Plan: High-Order SMIL Pseudo-Randomization

Because we decided on **Approach A (Pure SVG)**, I have implemented an extremely sophisticated synchronization trick. Each building has an individual opacity cycle duration (e.g., Building 1 runs on an 18s loop, Building 2 on a 14s loop, Building 3 on a 20s loop). Underneath each signboard, three distinct text nodes exist (e.g., "富", "Fu", and "不" for the Left group) which rotate their visibility over a long master cycle (e.g., 54 seconds for Building 1).

By coupling this with a signboard `display` animation that oscillates every alternative loop, we ensure that:

  1. Only some active buildings in a group hold a sign during any single cycle.
  2. Every time a building fades in, it shows a completely different word choice.
  3. This entire complex system runs purely on standard GPU-accelerated SVG vectors, compatible with all web browsers and markdown editors, with zero JS dependencies!
